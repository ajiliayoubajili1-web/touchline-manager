# Touchline Manager

An original football management and career-mode game, built from scratch.

The game's players are fully fictional. The Super League's club names and cities
echo famous real-world clubs, but every player identity is invented.
No EA SPORTS FC, FIFA, or Football Manager code, branding, or assets are used.

## Requirements

- Python 3.11+ (tested on 3.14)
- No third-party packages required

On Windows, use the `py` launcher if the `python` command is a store alias that
does not resolve to a real interpreter.

## Run

```bash
py run_game.py                 # start the game server and open the browser
py run_game.py --seed 7        # run with a specific world seed
py run_game.py --no-browser    # start without opening a browser
```

## Test

```bash
py run_tests.py                # discover and run the unittest suites
```

## Architecture

```
manager/
  core/        Domain models, enums, validation, ratings, valuation, serialization
  data/        Original fictional database generator (clubs, players, competitions)
  simulation/  Match simulation, fixtures, league tables            (Phase 3)
  systems/     Transfers, development, AI world, news, finances     (Phase 4-7)
  api/         Game action layer (UI-agnostic command/query surface)
  save/        Structured JSON save/load                            (Phase 2)
  ui/          HTTP server + frontend (HTML/CSS/JS)
run_game.py    Entry point
tests/         unittest suites
```

## Design principles

- Game logic is separated from UI; the UI only talks to the `api` layer.
- All simulation is deterministic when a seed is provided, so bugs are reproducible.
- Game-state changes flow through validated actions, so new mechanics can be
  added as hooks without rewriting existing systems.
- The database is generated by data generators (seeded), never hardcoded in UI files.

## Custom names

Open `custom_names.json` (created automatically, optional) to rename any club or
player — e.g. `"clubs": { "northbay": "BARCA" }` or
`"players": { "northbay.03": "MISSI" }`. Renaming is cosmetic and data-driven;
it never changes the generated database or the simulation. Unknown keys are
reported with a warning on startup and ignored.
